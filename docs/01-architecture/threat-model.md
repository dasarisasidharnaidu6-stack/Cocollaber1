# CoCollaber — Threat Model Specification (STRIDE)

**Document Stage:** Phase 1 Architecture Foundation  
**Status:** Approved Threat Model  
**Methodology:** Microsoft STRIDE Threat Modeling Framework aligned with OWASP Top 10 Application Security Risks.

---

## 1. Structured STRIDE Threat Analysis

| Threat ID | Asset Affected | Threat Scenario | STRIDE Category | Likelihood / Impact | Proposed Mitigation | Relevant Component | Verification Method | Residual Risk | Status |
|---|---|---|:---:|:---:|---|---|---|:---:|:---:|
| **TM-01** | User Identity | Attacker registers someone else's email or brute-forces login | **Spoofing** | Med / High | Email ownership verification token (24h expiry); Argon2id password hashing; rate limiting on `/login` | `apps/api/app/modules/auth/` | Unit test auth failures; test token expiration | Low | Designed (Phase 2 Impl) |
| **TM-02** | Opportunities | Non-creator attempts to edit, close, or delete an opportunity | **Tampering** | High / High | Enforce strict object-level check (`opportunity.creator_id == caller.id`) in service layer | `apps/api/app/modules/opportunities/` | Automated test submitting forged creator UUID | Negligible | Designed (Phase 2 Impl) |
| **TM-03** | Opportunity Pool | Scammers post deceptive investment, visa, or cash-advance schemes | **Tampering** / **Repudiation** | High / High | Mandatory compensation transparency; prohibited keyword flagging; prominent reporting buttons; human moderation | `apps/api/app/modules/moderation/` | Automated tests for prohibited terms; moderation queue test | Medium | Designed (Phase 1 DB, Phase 2 Logic) |
| **TM-04** | Seeker Labor | Creator misrepresents unpaid role as "internship with future pay" or demands uncompensated labor | **Information Disclosure** / **Tampering** | High / High | Mandatory explicit declaration of compensation type; compensation details string; caution banner in messaging | `apps/api/app/modules/opportunities/` | Schema validation rejecting missing compensation | Low | Designed (Phase 1 DB schema) |
| **TM-05** | Communication Channels | Spammers scrape profiles and send mass unsolicited pitch messages | **Information Disclosure** / **Denial of Service** | High / Med | Architectural firewall: 1-to-1 messaging strictly locked until mutual interest acceptance; max 1 interest per seeker | `apps/api/app/modules/interactions/` | Unit test attempting to message unaccepted user | Negligible | Designed (Phase 1 DB constraints) |
| **TM-06** | Member Well-being | Disgruntled user submits barrage of fake abuse reports against a legitimate creator | **Repudiation** / **Denial of Service** | Med / Med | Disallow automated auto-hide on N reports in P0 (SRS-OD-08); rate limit reporting; require reporter authentication | `apps/api/app/modules/moderation/` | Moderation queue load tests and report rate limits | Low | Designed (Phase 1 DB schema) |
| **TM-07** | Private Chat History | Unauthorized member attempts to read messages from another opportunity thread | **Information Disclosure** | High / Critical | Connection ID bound to participant UUIDs; query filters strictly by `caller_id IN (creator_id, seeker_id)` | `apps/api/app/modules/messaging/` | Penetration test attempting cross-tenant message read | Negligible | Designed (Phase 1 DB model) |
| **TM-08** | Staff Privileges | Regular member attempts to promote self to moderator or admin | **Elevation of Privilege** | Low / Critical | Role claims stored in protected `accounts.role` column, excluded from public registration/update schemas | `apps/api/app/modules/auth/` | Pydantic schema validation test ignoring `role` in payload | Negligible | Designed (Phase 1 DB model) |
| **TM-09** | Database Engine | Malicious input injected into search or filter queries | **Tampering** / **Information Disclosure** | Med / Critical | SQLAlchemy 2.0 parameterized queries exclusively; no raw string concatenation for SQL | `apps/api/app/db/` | SAST code scanning with Bandit / Ruff | Negligible | Implemented (Phase 1 ORM) |
| **TM-10** | Web Client (Next.js) | Malicious user injects JavaScript in opportunity description or chat message | **Tampering** | Med / High | Text trimming and script stripping (SRS GV-1); React default HTML escaping in Next.js App Router | `apps/web/src/` | Automated XSS payload test cases in pytest & Jest | Low | Designed (Phase 1 GV-1 standard) |
| **TM-11** | Application Secrets | Production API keys or database passwords committed to GitHub | **Information Disclosure** | Med / Critical | Pre-commit hook (`detect-private-key`); `.gitignore` rules; only `.env.example` templates committed | Repository Root | Git pre-commit verification; secret scanning CI | Negligible | Implemented (Phase 0 & 1) |
| **TM-12** | API Gateway | Attacker floods search endpoints or registration endpoints with bot traffic | **Denial of Service** | Med / Med | Strict rate limiting middleware per IP and per account (SRS Rate-Limit Table §12) | `apps/api/app/middleware/rate_limit.py` | Rate limit trip verification tests | Low | Designed (Phase 2 Impl) |
| **TM-13** | Log Files | Sensitive passwords, tokens, or personal identifiers printed in server logs | **Information Disclosure** | Med / Med | Sanitized structured logging middleware filtering `password`, `token`, `secret`, `authorization` keys | `apps/api/app/middleware/` | Log payload audit tests | Negligible | Designed (Phase 1 architecture) |
| **TM-14** | Administrative Power | Rogue admin suspends users or deletes content without accountability | **Repudiation** | Low / High | Mandatory non-repudiable logging of all privileged operations to `audit_logs` table with admin UUID | `apps/api/app/modules/admin/` | Automated test verifying audit log generation on action | Low | Implemented (Phase 1 DB model) |
